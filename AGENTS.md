# VCoder Story Demo — Codex Instructions

## Goal
Build a P0 clickable stakeholder demo for VCoder. This is a storytelling prototype, not production software.

## Hard scope
Frontend-only. No backend. No database. No auth. No real LLM scoring. No CI/CD. No telemetry.

## Source of truth
Read `docs/` before coding. Keep vocabulary aligned with PRD, Functional Spec, Rubric, and Test Plan.

## Canonical flow
Landing → Entry Test P1–P5 → Simulated AI Scoring → AI-Ready Profile → Learning Path → Gate Exam → Leaderboard → Dashboard.

## Canonical axes
Axis 1: AI Direction & Context Engineering  
Axis 2: AI Output Evaluation & Critical Review  
Axis 3: Recovery, Debug & Resilience  
Axis 4: Engineering Foundations  
Axis 5: AI Product & System Architecture

## Canonical levels
L0 AI-Curious  
L1 Vibe Coder  
L2 AI-Ready Engineer  
L3 Context Engineer  
L4 Agentic Engineer

## Prototype rules
Use realistic seed data.
Do not use lorem ipsum.
Make scoring clearly simulated.
Do not present fake AI scoring as validated.
Keep the UI polished enough for stakeholder demo.

## Tech
React + TypeScript + Vite + Tailwind + Recharts.
